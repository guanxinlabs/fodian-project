## 《无量义经》文件结构与体例

本目录继承项目 `00` 规则；各文件的正式用途和体例如下。后续新增内容必须以同类既有内容为直接模板，不得为单次回答自行调整结构。

| 文件 | 用途与固定体例 |
|---|---|
| `01 无量义经-经文原文.md` | 唯一权威原文母本：经名、译者、品名、纯经文。 |
| `02 无量义经-拼音阅读.md` | 与 `01` 对应，仅增加必要拼音。 |
| `03 无量义经-经文行法.md` | 行法事项、直接经文依据、边界说明。 |
| `04 无量义经-传统读诵仪轨.md` | 传统资料层，与经文行法分开。 |
| `05 无量义经-白话通译.md` | 按研习单元采用“第X段 → 原文 → 白话通译”。 |
| `06 无量义经-经义研习.md` | 逐段唯一编号台账；固定为“第X段 → 原文 → 白话通译 → 字词名相 → 经义研习 → 行持”。 |
| `07 无量义经-关键词索引.md` | 关键词、出处、原文、经内互证。 |
| `08 无量义经-修习记录.md` | 日期、所读经文、闻、解、行、验。 |
| `99 无量义经-修订记录.md` | 编号、位置、异文/疑点、依据、核定结果、状态。 |

### 结构变更控制

涉及本目录的文件名、用途、体例、段落编号或学习单元边界时，先更新项目 `00` 规则并取得维护者明确确认，再调整实际文件；未完成此前，保持既有结构。
