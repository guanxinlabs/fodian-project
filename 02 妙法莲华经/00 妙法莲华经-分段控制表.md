# 妙法莲华经分段控制表

> 本文件依据 `01 妙法莲华经-经文原文.md` 建立逐段研习边界。
> 本文件只控制：单元ID、品名、段号、原文起止、内容简述与锁定状态；不写白话通译、经义解释或个人体会。
> 当前版本为 `V1`，经维护者于 2026-11-24 明确确认，序品第一全部26个学习单元已锁定；其余二十七品尚未分段锁定。
> 正式研习必须严格继承已锁定边界；如确需调整，必须走项目级分段变更流程并保留新旧对应关系。

## 分段原则

1. 以 `01 妙法莲华经-经文原文.md` 为唯一文字母本。
2. 优先按说话主体变化、问答转换、叙事转换、偈颂起止、义理单元完整性及经文明确编号分段。
3. 不按字数平均切分；不因讲解方便临时拆段或合段。
4. 每品独立从第1段起编号，稳定单元ID采用 `MFH-Pxx-xxx`。
5. 单元身份以“单元ID + 品名 + 原文起点 + 原文终点”为准；标题/内容简述只作识别。
6. 表内起止定位仅为适应 Markdown 表格省略空白（包括偈颂句间全角空格及换行），标点和文字保持母本不变；提取原文时仍须恢复01原有空白、标点和排版。定位须唯一，按顺序连续覆盖全品。
7. 已锁定单元如需调整，必须走项目级分段变更流程并保留新旧对应关系。
